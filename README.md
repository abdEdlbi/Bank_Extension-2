# 🏦 نظام البنك (Bank System)

نظام إدارة حسابات بنكية بسيط مكتوب بلغة **C++**.

---

## 📌 وصف المشروع

هذا النظام هو تطبيق مصرفي يتيح لك:

* إضافة عملاء جدد
* البحث عن عميل برقم الحساب
* إيداع وسحب الأموال
* عرض جميع العملاء
* حفظ البيانات في ملفات نصية

تم تطويره كجزء من الكورس السابع في الخريطة البرمجية مع الدكتور محمد أبو هدهود.

---

## ✨ المميزات

* إدارة متعددة للحسابات
* حفظ البيانات في ملفات (File I/O)
* معالجة الأخطاء (Debugging)
* استخدام المؤشرات (Pointers) والمتجهات (Vectors)

---

## 🛠️ التقنيات المستخدمة

* **C++**
* **Vectors** لتخزين البيانات
* **Pointers** للتعامل مع الذاكرة
* **File I/O** لحفظ البيانات

---

## 🚀 كيفية التشغيل

1. تأكد من تثبيت مترجم **C++** (مثل GCC).
2. قم بتنزيل المشروع:


git clone [https://github.com/abdEdlbi/Bank_System.git](https://github.com/abdEdlbi/Bank_Extension-2.git)
افتح ملف الحل Bank_System(2).sln في Visual Studio.

اضغط F5 لتشغيل البرنامج.
